## 执行约束

- 保留已有 `../claude-code/` 样本，不覆盖其他 Claude agent 正在产出的代码或探测脚本。
- 新脚本、脱敏样本和报告只写各自目录。复用证据优先，真实请求只补缺口。
- 不读取、复制或打印凭据，不操作 Keychain，不修改用户的 Claude 配置；配置实验使用隔离的临时目录。
- 每项结论注明真实样本、离线验证、静态依据或未验证；不人为耗尽额度来制造错误。
- 不把 SDK 探测成功称为 miniclaw 产品验收通过。M0 收口后才能宣告进入 M11。
