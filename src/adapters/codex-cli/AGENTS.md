# Codex app-server adapter

- Implement the core EngineAdapter contract through a private stdio app-server, never the shared desktop daemon.
- M0 is chat-only: pass empty environments on thread and turn, disable executable/external features, hooks, skills, MCP and web search. Refuse all unexpected permission or dynamic-tool requests.
- Never read/copy auth.json or use Keychain; the engine reuses its own login through the normal HOME. Provider credential variables are not inherited.
- Keep one thread per EngineSession. Use turn/interrupt; never restart an interrupted turn automatically.
- Token usage is thread cumulative; subtract the previous turn baseline. Cost is unavailable, never estimate it as zero.
- Local protocol schemas were generated by the installed Codex into /private/tmp/miniclaw-codex-schema. Recheck after upgrading; do not claim mock tests are live model verification.
- The free thread/start probe returned readOnly, networkAccess false and approvalPolicy never on 2026-09-10. Global ~/.codex/AGENTS.md was still reported as an instruction source; full config/instruction isolation is not claimed.
